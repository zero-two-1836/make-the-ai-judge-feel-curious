# The Keeper's Log

A tiny program for the make.fun "Make the AI judge feel curious" competition. Running `main.py` writes a single short fragment to `/output/entry.txt`: forty years of identical lighthouse log entries, one voice never answered — and a final entry in different handwriting that raises far more questions than it settles.
